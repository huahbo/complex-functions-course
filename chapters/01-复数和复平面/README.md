# 第1章 复数和复平面

> 本章是复变函数的起点：从实数的“平面化”开始，建立复数、复平面、点集与扩充复平面的基本语言。

## 教学目标

1. 掌握复数的代数形式、几何表示、模与辐角、三角/指数形式；
2. 熟练进行复数的四则运算、乘方、开方，理解共轭与模的性质；
3. 理解复平面上的邻域、内点、开集、区域、边界、曲线、单连通等基本概念；
4. 了解扩充复平面与球面（黎曼球面）表示。

## 课时建议

- 复数的概念与运算：2 学时
- 三角形式、乘方与开方：1.5 学时
- 复平面点集：1.5 学时
- 扩充复平面与球面表示：0.5–1 学时（可结合课后阅读）

## 教学重点

- 复数的模与辐角（尤其是辐角多值性）；
- 复数的乘除法的几何意义；
- n 次方根（n 个单位根）；
- 区域与单连通/多连通区域的区别。
