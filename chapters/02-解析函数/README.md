# 第2章 解析函数

> 本章建立复变函数的核心框架：从复变函数的概念、极限与连续性出发，引入复变函数的导数与解析函数，给出函数可导与解析的充要条件（柯西-黎曼方程），并系统介绍复初等函数（指数、对数、幂、三角、反三角、双曲与反双曲函数）。

## 教学目标

1. 掌握复变函数的概念、几何（映射）意义与反函数；
2. 理解复变函数极限与连续的 $\varepsilon$-$\delta$ 语言，掌握用实部/虚部函数研究极限与连续；
3. 掌握复变函数导数的定义、求导法则，理解可导与解析的联系与区别，会判断函数的可导性与解析性并求出导数；
4. 掌握柯西-黎曼（C-R）方程，会用充要条件判断可导/解析；
5. 掌握复初等函数（指数、对数、幂、三角、反三角、双曲、反双曲）的定义、性质、多值性与主值分支。

## 课时建议

- 复变函数的概念、极限与连续性：2 学时
- 复变函数的导数与解析函数概念：2 学时
- 可导与解析的充要条件（C-R 方程）：2 学时
- 初等函数（指数、对数、幂、三角、反三角、双曲）：3–4 学时

## 教学重点

- 复变函数作为两个复平面间映射的几何意义；
- 复变函数极限存在与否的判定（沿路径、化为实部/虚部）；
- 导数定义与“可导必连续但连续未必可导”；
- 解析函数与奇点的概念；
- 柯西-黎曼方程及其使用；
- 复初等函数的多值性、主值分支与周期性。

## 教学难点

- 复变函数 $\Delta z\to0$ 的任意性对可导性的影响（如 $\bar z$、$z\operatorname{Re}(z)$）；
- 可导与解析的区别（一点可导 ≠ 该点解析）；
- C-R 方程只是必要而非充分，需配合可微（或偏导连续）；
- 对数的多值性、$\mathrm{Ln}(z^n)\neq n\mathrm{Ln}z$，以及幂函数、反三角、反双曲的分支选取；
- $\sin z,\cos z$ 在复平面上的无界性（与实变量区别）。
