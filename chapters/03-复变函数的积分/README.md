# 第3章 复变函数的积分

> 本章是复变函数论的核心内容之一：从复变函数沿曲线的积分出发，引出柯西-古萨定理、原函数、复合闭路定理、柯西积分公式与高阶导数公式，并揭示解析函数与调和函数的关系。这些结果是后续级数、留数理论的基础。

## 教学目标

1. 理解复变函数积分的定义与性质，掌握参数方程法计算积分；
2. 掌握柯西-古萨定理及其推论，理解单连通域内积分与路径无关、原函数与变上限函数；
3. 掌握复合闭路定理，能处理多连通区域上有孤立奇点时的积分；
4. 掌握柯西积分公式、高阶导数公式，并能计算典型闭路积分；
5. 理解解析函数的实部、虚部都是调和函数，掌握求共轭调和函数的三种方法。

## 教学重点

- 复变函数积分的定义与参数方程法；
- 柯西-古萨定理：单连通域内解析函数沿闭曲线积分为零；
- 原函数与牛顿-莱布尼茨型公式；
- 复合闭路定理：处理有奇点时的积分；
- 柯西积分公式与高阶导数公式；
- 解析函数的实部、虚部均为调和函数。

## 教学难点

- 积分 $\oint_C f(z)dz$ 的“存在性”定义及 $ML$ 估计；
- 格林公式与柯西-黎曼方程在柯西-古萨定理证明中的作用；
- 多连通区域、复闭路与“挖孔”技巧；
- 柯西积分公式证明中的 $r\to0$ 估计；
- 高阶导数公式中“导数阶数”与“极点阶数”的匹配；
- 求共轭调和函数时对“积分常数是 $x$ 的函数 $g(x)$”的理解。
