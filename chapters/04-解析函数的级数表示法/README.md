# 第04章 解析函数的级数表示法

> 本章是复变函数课程的“函数表示理论”核心：在复平面上，解析函数可以被幂级数（泰勒级数）在圆盘内表示，而在有孤立奇点（或环域）时可由洛朗级数表示。先用复数项级数建立“收敛”语言，再研究幂级数与泰勒/洛朗展式，最后利用洛朗展开对孤立奇点进行分类。

## 本章结构

| 小节 | 内容 | 对应幻灯片 |
| --- | --- | --- |
| 4.1 复数项级数 | 复数列极限、复级数收敛、绝对/条件收敛 | 第 2–10 页 |
| 4.2 幂级数 | 幂级数概念、收敛半径与收敛圆、比值/根值法、幂级数性质与解析性 | 第 11–24 页 |
| 4.3 解析函数的泰勒展开 | 泰勒定理、展式唯一性、解析与泰勒展式、零点阶数、常用展式 | 第 25–32 页 |
| 4.4 解析函数的洛朗展开 | 洛朗级数、收敛圆环、洛朗定理、圆环内的展开 | 第 33–42 页 |
| 4.5 孤立奇点 | 孤立奇点定义与分类、可去/极点/本性奇点、无穷远点 | 第 43–50 页 |

## 教学目标

1. 理解复数列与复级数收敛的判定（化归为两个实级数）；
2. 会求幂级数的收敛半径，理解收敛圆与边界敛散性；
3. 掌握解析函数的泰勒展开及常用初等函数展开；
4. 掌握解析函数在圆环内的洛朗展开；
5. 能依据洛朗展开对孤立奇点分类（可去、极点、本性），并处理无穷远点。

## 教学重点

- 复级数收敛与绝对收敛/条件收敛；
- 收敛半径的比值法、根值法；
- 泰勒级数与洛朗级数的展开、唯一性；
- 孤立奇点的分类（负幂项的有无与多少）。

## 教学难点

- 收敛半径与边界敛散性的关系；
- 泰勒定理证明中柯西积分公式 + 几何级数 + 余项估计；
- 洛朗级数在不同圆环内展开式不同，唯一性只在给定圆环内成立；
- 无穷远点奇点的判定（作 $z=1/t$ 变换后看正幂项）。

## 课时建议

- 复数项级数：1 学时
- 幂级数（含收敛半径、性质）：2 学时
- 泰勒展开：1.5 学时
- 洛朗展开：1.5 学时
- 孤立奇点：2 学时
- 合计约 8 学时（配合课后习题与本章小结）。

## 主要习题要点

- 判断复级数敛散与绝对收敛（例 4.1 类型）；
- 求幂级数收敛半径与和函数（例 4.2–4.4 类型）；
- 把函数展开成泰勒级数（例 4.5 类型）；
- 在给定圆环内求洛朗级数（例 4.6–4.7 类型）；
- 判别孤立奇点类型并求极点阶数（例 4.8 类型）。
