# 第6章 共形映射

> 本章是复变函数的几何分支：利用解析函数的导数刻画映射的“保角”性质，并借助分式线性变换、幂函数与指数函数等初等映射，把常用区域（角域、带形、半平面、单位圆）互相转化，为求解 Laplace 方程、热传导等边界值问题提供几何工具。

## 教学目标

1. 理解分式线性变换的定义、分解及“保广义圆、保交比、保角”等基本性质；
2. 掌握由三对对应点确定唯一分式线性变换的方法，会用标准映射把单位圆与上半平面互映；
3. 理解导数的几何意义（伸缩率与旋转角），掌握共形映射的定义与判定条件（`f'(z)≠0`）；
4. 掌握幂函数 `w=z^n` 与指数函数 `w=e^z` 构成的映射规律，会将其复合化为简单区域。

## 本章结构

| 小节 | 内容 | 主要工具 |
| --- | --- | --- |
| 6.1 分式线性变换 | 定义、分解、保广义圆、交比不变、三点定变换、单位圆与上半平面互映 | 平移、旋转伸缩、反演；交比 |
| 6.2 共形映射 | 导数的几何意义、共形映射定义与判定、局部单叶、区域对应、边界对应 | `f'(z)≠0`、反函数定理、开映射定理 |
| 6.3 几个初等函数所构成的映射 | 幂函数、指数函数的共形性与区域映射、复合映射 | `w=z^n`、`w=e^z`、分式线性变换 |

## 课时建议

- 6.1 分式线性变换：2.5 学时（含 1 学时典型例题与作图）
- 6.2 共形映射：2 学时
- 6.3 初等函数构成的映射：2 学时
- （可安排 0.5 学时作本章小结与习题课）

## 教学重点

- 分式线性变换的保广义圆性与交比不变性；
- 由三对对应点确定变换、单位圆与上半平面的标准互映；
- 导数的几何意义与共形映射的判定；
- 幂函数、指数函数的区域映射规律（角域、带形、半平面、单位圆）。

## 教学难点

- 无穷远点与广义圆的统一处理；
- 交比的计算与符号；
- “局部共形”与“整体单叶”的区别；
- 复合映射中单叶区域的选取与各步的共形性检查。
