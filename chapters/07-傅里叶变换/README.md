# 第07章 傅里叶变换

> 本章把周期信号的傅里叶级数推广到非周期信号，引进傅里叶变换，并引入单位脉冲函数 $\delta(t)$ 以处理不绝对可积的信号。核心内容为傅里叶变换的定义、性质、卷积定理及其在信号与系统中的应用。

## 教学目标

1. 理解傅里叶积分公式，掌握傅里叶变换与逆变换的定义及适用条件；
2. 会用定义的积分计算矩形脉冲、双边指数、单边指数等典型函数的傅里叶变换；
3. 理解单位脉冲函数 $\delta(t)$ 的广义函数含义、筛选性质与主要运算；
4. 掌握傅里叶变换的线性、位移、频移、尺度、对称、微分、积分与 Parseval 等性质；
5. 掌握卷积的定义、代数性质与卷积定理，并能用于求变换、求卷积和分析线性系统。

## 教学重点

- 傅里叶变换对的定义与符号约定（$e^{-i\omega t}$ / $e^{i\omega t}$、$\dfrac{1}{2\pi}$）；
- 矩形脉冲的 $\operatorname{sinc}$ 型频谱及“时域越窄、频域越宽”；
- $\delta(t)$ 的筛选性质，以及 $\mathcal F[\delta]=1$、$\mathcal F[1]=2\pi\delta(\omega)$；
- 时域微分/频域微分、频移/尺度等性质的运用；
- 卷积定理：时域卷积 $\Longleftrightarrow$ 频域乘积，时域乘积 $\Longleftrightarrow$ 频域卷积（带 $\dfrac{1}{2\pi}$）；
- 用 $\delta$ 与卷积处理不绝对可积信号、线性系统的冲激响应。

## 教学难点

- 从傅里叶级数的离散谱过渡到傅里叶积分的连续谱；
- 理解 $\delta(t)$ 是广义函数而非普通函数，以及 $\delta\cdot$ 与 $\delta*$ 的区别；
- 各性质中常数（$\dfrac{1}{|a|}$、$\dfrac{1}{2\pi}$、$\pi\delta$ 项）与符号约定；
- 分段函数卷积积分上下限的确定。

## 常见教学提示

- 先用“矩形脉冲、双边指数”两个可直接积分的例子建立“时域-频域”对应，再引入 $\delta$ 的广义化；
- 强调“符号约定一致 + 系数来源”，给出表格总结主要变换对与公式；
- 用 T 图说明“翻转—平移—重叠”的卷积过程，再引入卷积定理；
- 结合信号与系统：$y=x*h$、$Y=XH$，凸显傅里叶变换在频域分析中的作用。

## 常用变换对速查

| $f(t)$ | $F(\omega)$ |
| --- | --- |
| $\delta(t)$ | $1$ |
| $1$ | $2\pi\delta(\omega)$ |
| $u(t)$ | $\dfrac{1}{i\omega}+\pi\delta(\omega)$ |
| $e^{-at}u(t)$ | $\dfrac{1}{a+i\omega}$ |
| $e^{-a|t|}$ | $\dfrac{2a}{a^2+\omega^2}$ |
| $p_a(t)$ | $\dfrac{2\sin a\omega}{\omega}$ |
| $e^{i\omega_0 t}$ | $2\pi\delta(\omega-\omega_0)$ |
| $\cos\omega_0 t$ | $\pi[\delta(\omega-\omega_0)+\delta(\omega+\omega_0)]$ |
