# 第8章 拉普拉斯变换

> 本章是《复变函数与积分变换》的重要一章：把“傅里叶变换对绝对可积的要求”通过引入衰减因子 $e^{-\sigma t}$ 加以放宽，从而获得处理增长函数、因果信号与常系数线性微分方程初值问题的有力工具。第3版本章分四节：拉普拉斯变换的定义、性质、逆变换与应用。

## 教学目标

1. 理解拉普拉斯变换的引入动机，掌握定义 $\mathcal{L}[f(t)]=\int_0^{\infty}f(t)e^{-st}dt$（$s=\sigma+i\omega$）与收敛域；
2. 理解原函数存在定理（分段连续 + 指数型增长）；
3. 熟练运用线性、微分、积分、位移、延迟、相似、卷积、初值/终值等性质求象函数；
4. 掌握部分分式法、配方、卷积定理、留数法求拉普拉斯逆变换；
5. 会用拉普拉斯变换求解常系数线性微分方程（组）、卷积型积分方程与电路暂态等问题。

## 课时建议

- 8.1 定义与存在定理：2 学时（含基本变换推导与表）
- 8.2 性质：3 学时（微分性质与卷积定理为重点，配例题）
- 8.3 逆变换：2.5 学时（部分分式法为主，留数法可选）
- 8.4 应用：2.5 学时（微分方程初值问题为核心，电路与应用可结合工程举例）
- 总课时：约 10 学时（复习与练习另计）

## 教学重点

- 拉普拉斯变换的定义与收敛域；基本变换表；
- 微分性质及其“自动嵌入初始条件”的作用；
- 位移性质与延迟性质的区别与使用；
- 卷积定理（正用求变换、反用求逆变换）；
- 部分分式法求拉普拉斯逆变换；
- 用拉氏变换解常系数线性微分方程（组）。

## 教学难点

- 收敛坐标与收敛域的确定；
- $n$ 阶微分性质的初始项书写与符号；
- $s$ 域平移与 $t$ 域延迟（$e^{at}f(t)$ 与 $f(t-a)u(t-a)$）的区分；
- 终值定理的适用条件（虚轴/右半平面无奇点）；
- 重极点、复极点（配方法）的部分分式展开；
- 把应用问题（电路、积分方程）正确转化为 $s$ 域代数方程。
