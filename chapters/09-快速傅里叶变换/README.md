# 第09章 快速傅里叶变换

> 本章是“傅里叶变换”的自然延续，也是教材从连续信号走向离散信号处理的关键一章。它把连续时间傅里叶变换（CTFT）、离散时间傅里叶变换（DTFT）与 Z 变换统一起来，并最终落到工程上可编程实现的离散傅里叶变换（DFT）与快速傅里叶变换（FFT）。本章没有原始幻灯片，正文依据标准教材知识完整编写。

## 教学目标

1. 掌握离散时间傅里叶变换（DTFT）的定义、收敛性与基本性质，理解它与连续傅里叶变换的联系；
2. 理解 Z 变换的定义、收敛域（ROC）与常用性质，掌握 Z 变换与 DTFT 的关系；
3. 掌握离散傅里叶变换（DFT）的定义、矩阵表示、性质与圆周卷积；
4. 理解快速傅里叶变换（FFT）的基-2 时域抽取（DIT）思想、蝶形图与运算量，能进行简单的蝶形计算。

## 教学重点

- DTFT 的非周期、周期性与频谱叠加（采样定理背景）；
- Z 变换收敛域与极点、序列类型的对应关系；
- DFT 是对 DTFT 在单位圆上的等间隔采样，因而引入圆周卷积与频谱混叠；
- 基-2 时域抽取 FFT 的“分解—蝶形—重组”流程及运算量从 $O(N^2)$ 降到 $O(N\log N)$。

## 教学难点

- DTFT 与前几章连续傅里叶变换在符号与公式上的差别（求和 vs 积分）；
- Z 变换收敛域的判定（双边 Z 变换特别容易出错）；
- 圆周卷积与线性卷积的区别与联系（补零后圆周卷积等于线性卷积）；
- FFT 蝶形图中因子 $W_N^k$ 的符号、下标与位序重排（位反转）。

## 主要习题

本章未附独立习题卷；建议结合教材课后题与常见题型：计算 DTFT/DFT、判断收敛域、画 8 点基-2 DIT 蝶形图、比较 DFT 与 FFT 运算量。
